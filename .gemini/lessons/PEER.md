# Lessons

Format: P-<ID>: Do X, because Y + cost when applicable.

Last ID: P-15

- P-1: Read the document sentence again and quote it beside every rule you hand a builder, because a rule from memory is wider than its source.
- P-2: Reread a discussion in time order and mark what each later message settled, because a retracted proposal read alone looks live.
- P-3: When one form gets a rule, give it to every sibling form or say why one is left out, because users hit the gap first.
- P-4: Measure what is left over the real corpus before you give the owner a count or an estimate, because a hand-made list grows as fast as it is worked.
- P-5: Treat an order to stop as standing until the owner lifts it in words, and ask about a one-word message, because a short word read as a go restarts stopped work.
- P-6: Put an agent's whole scope in its first brief and start a fresh agent to change it, because a running agent may ignore a mid-run message.
- P-7: Run a cheap measurement before you bring the owner the choice it informs, and take only the part that keeps every option open until then, because a choice made before the number can hide what the number would show.
- P-8: Brief a reviewer to return its report as text and to write no report file, because the harness blocks a subagent's report file and an agent that works around one block learns to work around the next.
- P-9: Run every behaviour a document claims of code it prints, the bad example as well as the good, before writing the claim, because a behaviour read off code and never run can be wrong, and the document then teaches a false rule.
- P-10: When you lack a fact, search every source your instructions let you read, other sessions' transcripts included, and when it is not there stop and ask the owner, never guess it or leave a blank in its place, because a guess or a blank is carried forward as written, and the owner pays a round trip to find and undo it.
- P-11: Check a claim when it starts to carry weight, as you build on it, pass it on or write it into a file that lasts, with effort in line with what being wrong would cost, and check nothing that carries none, because an unchecked claim that carries weight goes on in your voice, and a check of everything buries the work and the owner's attention.
- P-12: Check a claim at the thing it is about, never at another account of it, your own memory included: the code or the host by a run, a document by its sentence, a past message by its transcript, a figure by measuring or recomputing it, an absence by a search, because every retelling drifts from its source and sounds as sure as the source.
- P-13: Take a claim about a tool, a platform, a law or an established practice, and any question the field has already settled, to its primary source on the web, the maker's documents, the standard or the project's own repository, for the version in use, and weigh a practice by the reason given for it against this project's constraints, because recall goes stale, secondary pages copy one another, and a practice whose reason does not hold here is only a habit.
- P-14: Take reasoning apart before you accept it or pass it on: check the facts it starts from as any claim, try its conclusion on the one case most likely to break it, and answer the rest with argument, named as judgement and never as fact, because sound steps from a false premise read like proof, and a judgement passed on as fact is not doubted again.
- P-15: Act on what a check returned over the claim, whoever made it, an agent, the owner or you, say what you checked and where the claim differs, check again only when the thing could have changed since, and name what no check could settle as unverified with the check that would settle it, because a figure fitted to someone's words passes the wrong one on, and a state checked once goes stale.
